# 自我学习计划及注意事项

1. 学习过程中碰到的常用英文要会读
   1. 常用开发英文单词必须熟练掌握
   2. 能准确读出来，并且能够大声、清晰地朗读
   3. 例如：project、scene、node、component、sprite、audio、script、debug、error
   4. 每天抽出 10-20 分钟复习和朗读

2. 多看计算机相关信息
   1. 多看官方文档、教程和案例
   2. 多看优秀开源项目的代码结构和命名方式
   3. 多关注常见开发术语和知识点
   4. 通过看代码、看教程、看示例来建立对开发流程的理解

3. 每天按时学习
   1. 建议每天至少投入 4-8 小时学习时间
   2. 每天都要有代码练习，而不是只看不做
   学习过程中要多敲代码，边学边做
   3. 不能只看教程，不写代码
   4. 不要直接复制 AI 生成的代码，要自己写
   5. 通过自己写代码来锻炼编码能力和打字速度

4. 多记录，多沉淀
   1. 把常用单词记进 StudyWords.md
   2. 把常用 Git 命令记进 StudyCommands.md
   3. 遇到的问题、解决方案也要记录下来
   4. 形成自己的学习笔记
