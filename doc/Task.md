# 任务清单

1. 学习 Cocos Creator 基础
   1. 重新建工程，每个工程的名字都必须有意义
   2. 先学习 2D 游戏开发基础
   3. 需要有 1 个工程，专门用于学习和测试各种组件，并写好每一个组件的示例

2. VS Code 编辑器
   1. 安装并配置常用插件
   2. 学习 VS Code 官方文档：https://code.visualstudio.com/docs
   3. 重点看：编辑器基础、调试、Extensions（插件）
   4. 学习 VS Code 调试教程：https://code.visualstudio.com/docs/editor/debugging
   5. 学习插件推荐：https://code.visualstudio.com/docs/editor/extension-gallery
   6. 常用插件：ESLint、Prettier、GitHub Copilot、Live Server、TypeScript 插件

3. 学习代码规范
   1. 学习 Google TypeScript 代码规范：https://zh-google-styleguide.readthedocs.io/en/latest/google-typescript-styleguide/contents.html
   2. 统一命名规范
   3. 代码缩进、注释和函数职责划分
   4. 养成阅读和维护代码的习惯

4. 学习浏览器调试工具
   1. 学习 Chrome 开发者工具：https://developer.chrome.com/docs/devtools/javascript?hl=zh-cn
   2. 学会使用 console.log 和断点调试
   3. 学习查看报错、资源加载和网络请求
   4. 能结合 Cocos 运行情况定位问题

5. GitHub 学习使用
   1. 学习 Conventional Commits 提交规范：https://www.conventionalcommits.org/zh-hans/v1.0.0/
   2. 学习 Git 基础命令（clone、commit、push、pull、branch、merge）
   3. 学习 GitHub 的基本使用流程：创建仓库、上传代码、提交记录
   4. 练习分支开发：每次开发都新建分支，在分支上完成任务，再合并到主分支
   5. 学习使用 Pull Request（PR）进行代码 review 和合并
   6. 学习 README 的编写，说明项目功能、使用方法和运行步骤
   7. 了解 Issues 的使用，用于记录任务、问题和待办事项
   8. 强迫自己使用简短英文提交，每次提交都使用英文描述，避免中文提交
   9. 每次提交格式统一为：type: subject，例如：feat: add player move
   10. 养成定期提交代码、保留提交记录的习惯
